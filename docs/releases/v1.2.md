# v1.2 "Fast"

**Tagged** 4 Nov 2026 at `67f1b18` ([GitHub Release](../../../../releases/tag/v1.2)). A checkpoint on the way to
[v2.0 "XLR8"](v2.0.md): the web UI rebuilt to load in under a second on a slow phone connection, plus interactive 3D
figures. No pipeline, image or infrastructure change since [v1.1](v1.1.md).

## Fast like Web 1.0 ([#226](../../../../pull/226))

- **No framework:** Pico CSS (82 KB) and htmx (51 KB) are replaced by about 13 KB of inlined CSS and 2.9 KB of plain
  JavaScript.
- **Speculation Rules prerendering** on hover (moderate eagerness), excluding downloads, uploads and status
  endpoints, plus a hover prefetch for other browsers. Pages are bfcache-friendly.
- **Hashed, immutable static assets**; the variant tables page at 50 rows, one URL per page; the fastp report opens
  only on request.
- **Lighthouse (mobile preset), the same data and server:**

| Page | Before | v1.2 |
| :--- | :--- | :--- |
| Sample list | 162 KB, LCP 1.36 s | **8.2 KB, LCP 0.76 s** |
| Sample detail | 520–1,618 KB, LCP 3.3–4.1 s | **9.8 KB, LCP 0.79 s** |

Score 100, CLS 0, TBT 0 on every page.

## Interactive 3D figures ([#227](../../../../pull/227))

- **The `/figures/` page:**
  - the coverage terrain;
  - the per-cycle quality surface;
  - the cost and turnaround terrains from the 25-run cloud grid ([#221](../../../../pull/221));
  - the DeepVariant batch × shards terrains ([#216](../../../../pull/216)).
- **The renderer:** hand-written WebGL (about 6 KB gzipped) in a Worker with OffscreenCanvas. That took Total
  Blocking Time from 0.87–1.37 s (Chrome's GPU-process cold start) to 0, with a fallback when no Worker is
  available.
- **Loading:** a static poster shows first; the 3D module and its data load only on scroll into view.
- **Interaction and accessibility:** drag, pinch and keyboard controls; hover readouts; colour-blind-safe palettes
  with legends; a 2D figure and CSV as the accessible alternative.
- **Lighthouse on `/figures/`** with a 3D chart loaded: 22.9 KB, LCP 0.71 s, score 100.

Before merging, an independent code review found and fixed several bugs: a cost reader on invented columns, two
server errors, prerender rules missing paged URLs, and a stale-manifest fallback.
