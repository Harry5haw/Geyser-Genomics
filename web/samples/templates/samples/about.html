How it works

Geyser Genomics takes the raw reads from a DNA sequencer and finds where that genome differs from the human reference: the variants. Every run is checked for quality and gets its own page here. It runs on AWS on demand, so it costs nothing while it waits, and the same containers run on a laptop with no cloud at all.

From raw reads to variants

  1. Upload. A gzipped FASTQ (one file, or the R1 and R2 files of a pair) lands in storage, and that alone starts the run: nobody launches the stages by hand.
  2. Quality control and alignment, side by side. fastp reports on the reads' quality while bwa-mem2 places every read on the reference genome, sorts them and marks duplicates (a CRAM file).
  3. Variant calling. bcftools by default, split by region into jobs that run in parallel and are merged into one VCF; or DeepVariant, Google's deep-learning caller, on a cloud GPU.
  4. The quality gate. A run can finish and still not be good enough: a small Rust program checks read quality, mapping, duplicates, depth, breadth and Ti/Tv against calibrated thresholds and names every failed check.
  5. Optional AI annotation. AlphaGenome, Google DeepMind's model, predicts how variants of interest may change gene regulation. Research use only, not for clinical use.
  6. A page per run. The calls, QC, gate verdict and a run record (inputs, reference, tool versions, each stage's timing) are published to this site when the run ends.

On AWS: an S3 upload event, a Lambda trigger, Step Functions and AWS Batch (Fargate, and EC2 GPUs for DeepVariant), all from Terraform. A 30x chromosome 20 sample takes about 22 minutes and costs about $0.07.
